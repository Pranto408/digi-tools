# DigiTools 🚀
-Project Name : Digi Tools
## 📖 Description
DigiTools is a simple web app where users can browse digital tools, add them to a cart, and manage selected items easily. It has a clean and responsive design.

---

## 🛠️ Technologies Used
- React.js  
- Tailwind CSS  
- DaisyUI  
- JavaScript  
- Vite  

---

## ✨ Features
- 🛒 Add and remove items from cart  
- 📦 View selected items in cart  
- 🎨 Responsive and user-friendly UI
